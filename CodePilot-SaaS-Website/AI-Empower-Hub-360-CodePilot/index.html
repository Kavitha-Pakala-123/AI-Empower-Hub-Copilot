FREQUENTLY ASKED QUESTIONS

Good questions.
Clear answers.

Can I use CodePilot with Ollama?

Yes. The local development server can connect to an Ollama model installed on the same computer. Start Ollama before using AI chat.

Does CodePilot write files or deploy apps automatically?

Not yet. The AI assistant provides text guidance. Automated file editing, test execution, and deployment require separate integrations and safety controls.

Can I buy a subscription today?

No. Subscription tiers are future plans. Payments and customer accounts have not been activated.

Are customer accounts available?

No. The current sign-in screen is a demo and must not be used for real credentials.
